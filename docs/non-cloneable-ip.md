# Non-cloneable IP policy

GitHub cannot make a repo “unclonable” for someone who already has access.
We achieve the practical outcome as follows:

| Layer | Mechanism |
| --- | --- |
| Public | Teaser only — cloning yields **no enabling IP** |
| Private vault | Invite-only; empty of full claim sets by default |
| Counsel pack | Shared outside git (encrypted channel) under NDA |
| Engineering demos | Public studios prove operator skill **without** publishing inventions |

Cloning this public repository is allowed and expected.  
It will not yield patent specifications.
