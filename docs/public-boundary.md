# Public boundary — patents teaser

## Allowed
- Family IDs and public marketing titles
- High-level status words (draft / in preparation / filed — when accurate)
- Contact path for counsel-controlled disclosure
- Links to **non-patent** public engineering studios

## Forbidden
- Claims, abstracts that enable, drawings that enable, code that practices claims
- Provisional PDF/DOCX bodies
- Parameter tables, σ ladders, cell counts used as inventive disclosure
- Customer names tied to confidential deployments

## Rule
If unsure whether a paragraph enables the invention, **do not publish it**.
